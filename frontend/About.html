ABOUT THE PROJECT

Understanding the heartbeat, one beat at a time.

ECG Assistant is a machine-learning prototype designed to classify heartbeat segments and demonstrate one way artificial intelligence can be applied to ECG data.

What it does

The system analyses a numerical heartbeat segment containing 200 values and predicts one of four heartbeat categories.

How it works

The heartbeat values are standardised and passed to a trained convolutional neural network (CNN). The model returns a predicted category and confidence scores for the four classes.

Its purpose

This project provides a practical demonstration of machine learning in ECG signal classification and serves as a foundation for further learning and development.

Important limitations

ECG Assistant is an educational prototype, not a clinically validated diagnostic system. It currently accepts numerical heartbeat data and does not directly analyse ECG images or connect to ECG equipment.

Designed for learning and exploration

Predictions should not be used to make medical decisions. Always consult a qualified healthcare professional for ECG interpretation and medical advice.
